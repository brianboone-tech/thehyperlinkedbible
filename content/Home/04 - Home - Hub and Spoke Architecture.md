## The Inline Link System

### Concept: Everything Connects Directly from Each Verse

![[Resources/Vault Architecture - Current.png]]

The Hyperlinked Bible uses **inline links** at the end of each verse. Instead of navigating to a separate page, you click directly from the verse to the resource you want:

![[Resources/Inline-Links-Example.png]]

### The Link Types:

- <span style="color: #3b82f6; font-weight: bold;">9</span> (verse number) → Reference Bible with Hebrew/Greek lexicon
- <span style="color: #7c3aed; font-weight: bold;">IP</span> (Intertextuality Pair) → How this verse is quoted/echoed in other passages
- <span style="color: #7c3aed; font-weight: bold;">C</span> (Chiasm) → Literary structure containing this verse
- <span style="color: #7c3aed; font-weight: bold;">TOSK</span> (Treasury of Scripture Knowledge) → Comprehensive cross-references
- <span style="color: #7c3aed; font-weight: bold;">TT</span> (Trajectory Table) → Typological development from shadow to substance

### Multiple Links of Same Type

When a verse has multiple connections of the same type, superscripts distinguish them:

![[Resources/Multiple-IP-Example.png]]

![[Resources/Multiple-TT-Example.png]]

### The Flow:

1. **Read Scripture** in the Readable Bible
2. **See the inline links** at the end of each verse
3. **Click the link type** you want to explore:
   - **IP** → See how other passages quote, allude to, or echo this verse
   - **C** → View the chiastic structure
   - **TOSK** → Browse comprehensive cross-references
   - **TT** → Trace typological fulfillment from OT to NT
