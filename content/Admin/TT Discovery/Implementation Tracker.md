## Trajectory Table Formatting Standards

**Last Updated**: 2025-12-14 (after standardization of ~140 files)

### File Naming Convention

**IMPORTANT:** All newly created trajectory tables MUST have filenames starting with "-- " (two dashes and a space):
- `Trajectory Tables/-- [Name].md`
- Example: `-- Enoch (Translation Without Death).md`

This distinguishes newly created tables from legacy tables and groups them together in file listings.

### File Format

All trajectory tables MUST follow this standardized format:

### File Structure

```markdown
## [NAME] TRAJECTORY TABLE

![[image.png]]  ← OPTIONAL: Only if image exists in Admin/PDFs and Images/

[Introductory paragraph - 3-5 sentences explaining the type, its development
through Scripture, and how it points to Christ. NO "Related Books:" line.]

**Type Classification**: [Direct/Providential] ([description]) and [Forward/Backward-Looking] ([description]).

| # | Stage | Key Text(s) | Theological Development | Text Analysis |
|---|-------|-------------|------------------------|---------------|
| 1 | **Stage Name** | [[link]] | Description. **CRITICAL:** [[pair link]] | [[Foundation link]] |
| 2 | **Stage Name** | [[link]] | Description. | [[Foundation link]] |
...

---

## Canonical Intertextuality Pairs

### OT to OT

**## - Book**
- [[pair link]] - **CRITICAL:** Annotation paragraph explaining connection.

### NT to OT

**## - Book**
- [[pair link]] - **CRITICAL:** Annotation paragraph explaining connection.

---

## Foundation Texts

[[link1]] | [[link2]] | [[link3]] | [[link4]] | ...
```

### Formatting Rules

| Rule | Correct | Incorrect |
|------|---------|-----------|
| **Related Books** | OMIT entirely | `**Related Books:** [[...]]` |
| **Type Classification** | Separate bold line after intro | Embedded in intro paragraph |
| **CRITICAL markers** | `**CRITICAL:**` before key pairs | Missing or inconsistent |
| **Separators** | Single `---` | Double `---\n\n---` |
| **Foundation Texts** | Pipe-separated single line | Separate lines |
| **Book names in pairs** | `**## - Book**` | `**Book**` without number |
| **Table links** | `[[path\|display]]` (backslash-pipe) | `[[path|display]]` |
| **Statistics/Analysis** | OMIT entirely | Include analysis sections |
| **Image embeds** | Keep if present | Remove |

### Type Classification Format

The Type Classification MUST be:
1. A **separate bold line** after the intro paragraph (not embedded in intro)
2. Format: `**Type Classification**: [Type] ([explanation]) and [Direction] ([explanation]).`

**Example:**
```markdown
**Type Classification**: Direct Type (divinely instituted feast) and Forward-Looking
(1 Corinthians 15:20 explicitly identifies Christ as "the firstfruits").
```

### CRITICAL Markers

Use `**CRITICAL:**` to mark the most important intertextuality pairs:

1. **In Theological Development column**: Place before inline pair links
   ```markdown
   Description of stage. **CRITICAL:** [[Intertextuality Pairs/...|Display]]
   ```

2. **In Canonical Intertextuality Pairs section**: Place before annotation
   ```markdown
   - [[pair link]] - **CRITICAL:** This connection shows...
   ```

### Foundation Texts Format

Foundation Texts section should be a **single pipe-separated line**:
```markdown
## Foundation Texts

[[link1]] | [[link2]] | [[link3]] | [[link4]] | [[link5]]
```

NOT separate lines:
```markdown
## Foundation Texts

[[link1]]
[[link2]]
[[link3]]
```

### Columns (5 Required)

| Column | Content |
|--------|---------|
| **#** | Sequential row number |
| **Stage** | Bold stage name (`**Name**`) |
| **Key Text(s)** | Readable Bible links |
| **Theological Development** | Explanation with CRITICAL markers where applicable |
| **Text Analysis** | Foundation Text links |
