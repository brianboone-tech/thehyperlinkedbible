## Resume Instructions

To continue the conversion at next session:

1. **Start command:** "Continue converting the Scripture Titles and Symbols book"

2. **Next PDF to read:** `pg 81-100` (Seventh and Eighth Sundays)

3. **Process pattern for each title:**
   - Create individual `.md` file named after the title
   - Include Scripture reference with Readable Bible link
   - Note which Sunday it belongs to
   - Include full content from the PDF
   - Add Previous/Next navigation links
   - Add attribution footer

4. **File naming convention:** `[Title Name].md` (e.g., `Anchor.md`, `Advocate.md`)

5. **Link format for Scripture references:**
   ```
   [[Readable Bible/[##] - [Book]/[Book] [Ch]#[Book] [Ch] . [V]|[Book] [Ch]:[V]]]
   ```

## Notes

- Book title on cover says "Two Hundred and Fifty" but title page says "Two Hundred and Eighty" - the actual count is 280 titles
- Author: James Large
- Publisher: Hodder and Stoughton, London, 1885
- Organized alphabetically within 52 Sunday readings
- Some titles are brief (covered under analogous heads), others are extensive
- Personal types included: Adam, Aaron, David, Moses, Joseph, Joshua, Melchizedek, Solomon, Michael, Zerubbabel, Eliakim
