## PROJECT OVERVIEW

### Purpose
Create comprehensive foundation text files for every key text referenced in the 40 TOSK (Treasury of Scripture Knowledge) Trajectory Tables. These foundation texts provide:
- Deep theological analysis of each passage
- Hebrew/Greek lexicon integration
- Biblical-theological connections
- Christological fulfillment
- Redemptive-historical context

### Methodology
Each TOSK Trajectory Table (e.g., "Sabbath (Rest in Christ)") receives:
1. **Dedicated folder** in `TOSK Foundation Texts/`
2. **Individual MD file** for each distinct verse reference in the table
3. **Full ninefold analysis** format (see below)
4. **Comprehensive Christological connection** section


### File Naming Convention
Format: `## - Book Reference.md`
- `##` = Two-digit book number (01-66)
- `Book` = Full book name
- `Reference` = Chapter.Verse or Chapter.Verse-Verse

Examples:
- `02 - Exodus 25.8-9.md`
- `19 - Psalm 110.4.md`
- `58 - Hebrews 7.23-24.md`

### Standard File Contents

Each foundation text file includes:

#### 1. Header with Readable Bible Link
```markdown
### [[Readable Bible/##-Book/Book Ch#Book Ch . V|Book Ch:V]]
```

#### 2. Hebrew/Greek Key Terms Section
- 5-10 key terms from the passage
- Lexicon links: `[[Lexicon/H####-####|Hebrew]]` or `[[Lexicon/G####-####|Greek]]`
- Transliteration and translation provided

#### 3. Context Section
3-5 sentences summarizing the passage's immediate context and theological significance.

#### 4. Connections Section
Three subsections:
- **TO**: Earlier OT passages this text builds on
- **FROM OT**: Later OT passages that develop this theme (if applicable)
- **FROM NT**: NT passages that fulfill or apply this text

All connections use Readable Bible link format.

#### 5. Ninefold Analysis Section
Standard 6 categories (consistently applied across all files):
- **OT Context**: Historical, canonical, redemptive-historical background. For OT texts: original setting, literary context, theological significance in Israel's history. For NT texts: how the passage builds on OT foundations and develops the theme.
- **Jewish Backgrounds**: Second Temple Judaism, rabbinic interpretation, cultural context. Includes Mishnah, Talmud, Qumran texts, Philo, Josephus, intertestamental literature.
- **Text Form**: Literary structure, grammar, syntax, verbal patterns, rhetorical devices. Analyzes how the text is constructed and what that reveals about authorial intent.
- **Hermeneutical Use**: How NT interprets OT texts (for OT passages), or how NT authors use hermeneutical principles (for NT passages). Includes typology, fulfillment, promise-fulfillment patterns.
- **Theological Use**: Doctrinal significance, systematic theology, biblical theology. What theological truths does this text establish or develop? How does it contribute to the biblical-theological trajectory?
- **Rhetorical Use**: Persuasive features, emphasis, literary effect. How does the text function in its context to persuade, teach, or move the reader?

#### 6. Christological Connection Section
Comprehensive paragraph (150-250 words) showing:
- How Christ fulfills this text
- Redemptive-historical progression
- Application to believers
- Eschatological consummation
- Multiple Scripture cross-references

## TECHNICAL NOTES

### Lexicon Range Format
**Hebrew**: `[[Lexicon/H####-####|Hebrew word]]`
- Example: `[[Lexicon/H7676-7677#H7676|שַׁבָּת]]`
- Ranges: H0001-0100, H0101-0200, etc. (100-number increments)

**Greek**: `[[Lexicon/G####-####|Greek word]]`
- Example: `[[Lexicon/G4520-4521#G4520|σαββατισμός]]`
- Ranges: G0001-0100, G0101-0200, etc. (100-number increments)

### Readable Bible Link Format
```markdown
[[Readable Bible/##-Book/Book Ch#Book Ch . V|Display Text]]
```
**Critical**: Verse anchors use PERIODS not hyphens
- Correct: `#Hebrews 4 . 9`
- Wrong: `#Hebrews 4-9`

### Book Numbers Reference
```
OT: 01=Genesis through 39=Malachi
NT: 40=Matthew through 66=Revelation
```
